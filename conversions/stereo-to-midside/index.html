Algorithm Description

Stereo to Mid/Side Encoder (Stereo → Mid-Side) Encodes a 2-channel stereo signal into a 2-channel Mid/Side (M/S) representation, tagged with subtype="midside". The Mid/Side encoding separates the stereo signal into: M (mid) = (L + R) * 0.5 — mono-compatible centre content S (side) = (L − R) * 0.5 — stereo difference / width content The 0.5 scale factor ensures a perfect round-trip with the matching midside-to-stereo decoder (L = M + S, R = M − S). Output channel layout (subtype="midside"): Channel 0 M — mid (sum) Channel 1 S — side (difference) Channel count: 2 (plain stereo) → 2 (subtype="midside") Use the midside-to-stereo graph to decode back to plain stereo.
