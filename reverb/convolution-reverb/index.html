Algorithm Description

Convolution Reverb Applies the acoustic character of a physical space (or any linear system) to an audio signal by convolving it with an impulse response (IR) loaded from a sampler. This models reverberation caused by reflections in a room, hallway, concert hall, or other acoustic environment. Algorithm: The impulse response is sampled from the bound "impulse_response" sampler starting at position 0 (the first blockSize samples of the IR file are used as the convolution kernel — see the note below). The input signal and that IR window are convolved via FFT multiplication, then the result is wet/dry mixed with the original dry signal. Note on IR length: This graph applies a single-block FFT convolution, which is accurate only when the impulse response is shorter than or equal to one block. For longer IRs (typical in real-world convolution reverb), an overlap-add or overlap-save scheme partitioned across many blocks is required. This graph therefore serves as a reference implementation and as a building block for more advanced partitioned-convolution engines. Sampler: Bind a mono WAV file containing the impulse response to the sampler named "impulse_response" before rendering. The file should be at the same sample rate as the graph (48000 Hz by default). Parameters: wet_level [0, 1] – reverberant (wet) signal amplitude (default 0.5) dry_level [0, 1] – original (dry) signal amplitude (default 0.5) Usage (standalone — this is a top-level graph): Compile this file directly. At runtime, bind the IR WAV to sampler 0 ("impulse_response") via crag_bind_audio_by_index(0, ptr, len). Usage (as a named subgraph via crag.include): crag.include "standard-graphs/reverb/convolution-reverb.crag.mlir" as "conv_reverb" ... %wet = crag.subgraph_ref "conv_reverb"(%dry) : (!crag.audio<f32, 48000, 1>) -> !crag.audio<f32, 48000, 1>
